# JUnit Maven

Projeto de estudos com Java, Maven e JUnit, reunindo exemplos de testes unitários, assertions, assumptions, testes condicionais, exceções e ordenação de execução.

## Boas práticas para testes unitários

1. Busque a simplicidade: use nomes objetivos, facilite a leitura dos testes e mantenha o código legível.
2. Comece a testar cedo: escreva testes o mais próximo possível da criação do código de execução.
3. Busque padronização: mantenha uma nomenclatura consistente para classes, métodos e cenários de teste.
4. Crie testes determinísticos: o mesmo teste deve produzir o mesmo resultado em cada execução, sem depender de variáveis instáveis.
5. Economize tempo automatizando: use ferramentas de cobertura de código e automatize a execução dos testes.
